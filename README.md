# Сайт веб-аналитика Натальи Авдеевой

Статическая версия сайта avd-web.tilda.ws для бесплатного хостинга на GitHub Pages.
В отличие от бесплатного тарифа Tilda, здесь подключена Яндекс Метрика (счётчик 113719924) с целями на клики.

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Главная страница |
| `privacy.html` | Политика конфиденциальности |
| `css/style.css` | Оформление |
| `js/main.js` | Метрика, цели, cookie-баннер, мобильное меню |
| `images/` | Логотип (`logo.svg`, `logo.png`), иконки вкладки (`favicon-32.png`, `apple-touch-icon.png`), аватарка для соцсетей (`avatar-512.png`), фото (`photo.jpg`) |
| `robots.txt` | Настройки для поисковиков |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Перед публикацией

1. **Политика конфиденциальности.** В `privacy.html` впишите отчество вместо `[Отчество]` и покажите текст юристу.

## Как опубликовать на GitHub Pages

1. Зарегистрируйтесь на github.com.
2. Создайте репозиторий: **New repository** → имя, например, `avd-web` → **Public** → **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **содержимое** этой папки (не саму папку). Нажмите **Commit changes**.
   Файл `.nojekyll` скрытый — если он не перетаскивается, создайте его в GitHub: **Add file → Create new file**, имя `.nojekyll`, содержимое пустое.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/avd-web/`.

### Свой домен (по желанию)

Купите домен (например, `avdeeva-analytics.ru`), в **Settings → Pages → Custom domain** впишите его, а у регистратора домена добавьте DNS-записи, которые покажет GitHub. Затем включите **Enforce HTTPS**.

## Яндекс Метрика

- Счётчик подключается **только после нажатия «Принять»** в cookie-баннере. Если посетитель отказался, данные не собираются.
- Включены: карта кликов, Вебвизор, отслеживание ссылок, точный показатель отказов.
- В настройках счётчика в Метрике укажите адрес нового сайта.

### Цели — создать в Метрике

Метрика → **Цели** → **Добавить цель** → тип **JavaScript-событие** → идентификатор:

| Идентификатор | Когда срабатывает |
|---|---|
| `click_order` | Клик по любой кнопке «Заказать» / «Узнать подробнее». В параметре `service` — какая услуга |
| `click_phone` | Клик по номеру телефона |
| `click_email` | Клик по почте |

Значения параметра `service`: `hero_audit`, `hero_free_call`, `sale_check`, `ux_review`, `year_report`, `templates`, `consultation`, `audit`, `setup`, `support`.

## Как менять тексты

Все тексты лежат в `index.html` — откройте файл на GitHub, нажмите на карандаш (**Edit**), поправьте текст и нажмите **Commit changes**. Сайт обновится через 1–2 минуты.

Блок «Актуально сейчас» (`id="actual"`) — сезонный, после Нового года его стоит обновить.
